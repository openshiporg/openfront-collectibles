# Storefront (customer) surface brief

Scope: every customer route under `/[countryCode]`: home, store, sets and set checklists, categories, collections, product (single, slab, sealed), search, buylist and trade-in, cart, checkout, order confirmation, account (binder, want list, trade-ins and every existing section). Mode: Persuade on home; Operate everywhere else. Audience and job are in PRODUCT.md. Constraints: every route, state and workflow stays; the owner pinned a dark, premium aesthetic; card UI is our own slice in `features/storefront/components/cards/`, designed from scratch, mobile-first, and shared with platform pages (owner, 2026-10-25: no third-party card UI library, code, CSS or tokens).

## Direction contract
THESIS: The shop is a set checklist. Every set is a numbered sheet, ticked where the shop holds a copy, each row carrying its condition run, market reading and price; a card opens from its number. It refuses the marketplace grid of identical product cards and the holo-gradient glow page.
OWN-WORLD: Black checklist stock with printed paper-white rows on hairline rules; the square tick box is the one control shape; card-border yellow (the store's logo hue) is the only ink accent: ticks, the primary action, the active number. Set logos and card art are the only other colour. Archivo throughout, condensed for numbers and stamps, normal width for names. Square corners, no shadows, no gradients.
STORY: The collector lands on the newest set's sheet, sees what is in stock and at what price, adds a card in one tap or searches by name or number; moves set to set from the index; reads slabs by their label and sealed product by its box end; sells through the buylist (the same sheet, read as what the shop is buying); keeps a binder of what they own and a want list of what they don't.
FIRST VIEWPORT: Left column about 38%: the store's name, one line naming singles, slabs, sealed and buylist, a working search for a card name or number, then the set index as a numbered list with logos, newest first, the upcoming set marked Pre-order. Right about 62%: the featured set's sheet: logo, code, release date, "N of M in stock", then ten printed rows (tick, number, name, rarity mark, NM-to-DMG run, price, Add). Add on each row is the primary action and really adds to the cart.
FORM: Set checklist, number 4 on my ordered list (1 nine-pocket binder page, 2 card-show dealer table, 3 graded-slab label, 4 set checklist, 5 the card's own collector-number strip, 6 shop glass showcase, 7 price-guide board). seed:e18d20c5562a90b0. Raises: split-flap board: one fixed column grid (No., Name, Rarity, Run, Price) on every list, and a changed price restyles its cell without breaking the grid. ASCII render: one ink, its state ramp (solid tick in stock, hollow box out, dashed box wanted or pre-order). Matchbook drawer: a sold-out row keeps its place on the sheet, struck, offering the want list. J-card: the number is the navigation (jump to a number on every sheet). Brine calendar: every row banded with its market reading and the date it was observed. Sneaker boxes: the condition run read like a size run, each live cell a buy target. Signature interaction: on hover or focus the card's art slides out of its number slot beside the row; on touch, tapping the number opens it in place. Motion grammar: rows print in by number once; a tick inks in.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
